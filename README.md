# FP2級 弱点集中問題集 PWA

AndroidタブレットのChromeで使う、外部ライブラリ・CDN・有料サービス不要の静的PWAです。金融資産運用と不動産を最優先にし、ライフプランニング、リスク管理、実技計算を次の重点分野として扱います。

## 主な機能

- 学科6分野と実技・計算の選択
- 弱点集中、ランダム、模擬試験、間違えた問題、お気に入りの各モード
- 四択・数値入力、解答後の解説・計算手順・注意点・制度基準日・出典表示
- 全体／分野別正答率、回答数、連続正解数、苦手表示
- 誤答回数・正答率・重点度による重み付き再出題
- localStorageによる学習履歴、お気に入り、途中経過、試験日の保存
- JSONバックアップのエクスポート／インポート
- ダークモード、オフライン表示、インストール対応
- 完全オリジナル問題30問

## PCでの動作確認

`file://`で直接開くと、ブラウザーの制限により`questions.json`の取得とService Workerが動きません。簡易Webサーバーを使ってください。

```bash
cd fp2-pwa
python3 -m http.server 8080
```

Chromeで `http://localhost:8080/` を開きます。停止はターミナルで `Ctrl+C` です。

## Androidタブレットへの導入

最も簡単な方法はGitHub PagesでHTTPS公開することです。

1. この7ファイルをGitHubリポジトリのルートに置きます。
2. GitHub Pagesを有効にします。
3. AndroidタブレットのChromeで発行されたURLを開きます。
4. 初回表示後、Chromeのメニューから「アプリをインストール」または「ホーム画面に追加」を選びます。
5. 一度オンラインで最後まで読み込んだ後は、主要機能をオフラインで利用できます。

## オフライン確認

1. オンラインでアプリを開き、問題が表示できることを確認します。
2. Chromeのタブを閉じます。
3. Androidの機内モードをオンにします。
4. ホーム画面のアプリアイコンから起動します。
5. 画面上部に「オフライン利用中」と表示され、出題・採点・履歴保存ができれば成功です。

## GitHub Pagesで無料公開

1. GitHubにログインし、`fp2-pwa`などのPublicリポジトリを作成します。
2. 「Add file」→「Upload files」から7ファイルをアップロードし、コミットします。
3. リポジトリの「Settings」→「Pages」を開きます。
4. 「Build and deployment」のSourceを「Deploy from a branch」にします。
5. Branchを`main`、フォルダーを`/(root)`にして「Save」を押します。
6. 数分後に表示される `https://ユーザー名.github.io/リポジトリ名/` を開きます。
7. 更新時はファイルを差し替え、`service-worker.js`の`CACHE_VERSION`を例として`fp2-pwa-v1.0.1`へ上げます。

## 問題データの編集

`questions.json`はJSON配列です。既存の1問を複製して、`id`を重複しない値へ変更してください。四択は`type: "choice"`、正解は0〜3の選択肢番号です。数値入力は`type: "number"`とし、`numeric`に単位、指示、許容差、刻みを設定します。

必須項目：

- `id`, `category`, `exam`, `difficulty`, `priority`, `type`, `prompt`
- `choices`（四択のみ）または`numeric`（数値入力のみ）
- `answer`, `explanation`, `formula`, `trap`, `basisDate`, `sources`

制度数値を含む問題は、公式URL、確認日、法令・制度の基準時点を必ず更新してください。

## よくある不具合

- **問題が読み込めない**：`file://`ではなくHTTP/HTTPSで開き、7ファイルが同じ階層か確認します。
- **インストール項目が出ない**：HTTPSのGitHub Pagesで開き、Chromeを最新版にし、ページを再読み込みします。端末やChromeの版により表示名が「ホーム画面に追加」の場合があります。
- **更新した問題が反映されない**：`service-worker.js`の`CACHE_VERSION`を変更して公開し直し、Chromeで再読み込みします。必要ならサイト設定から保存データを削除します。
- **オフラインで開かない**：オンライン時に一度完全に読み込み、Service Worker登録後に再読み込みしてから機内モードで試します。
- **履歴が消えた**：Chromeのサイトデータ削除、シークレットモード、ストレージ自動削除でlocalStorageが消えることがあります。定期的にJSONエクスポートしてください。
- **インポートに失敗する**：JSON構文、必須項目、重複ID、四択の選択肢数、分野名を確認します。
- **残日数がずれる**：端末の日付、時刻、タイムゾーンを自動設定にします。
